A mowing crew route planner for the City of Lawton, Oklahoma Parks and Recreation department. This software will automate route generation for the 4 parks crews on a biweekly basis and will be an educational process for myself as I am learning the C# language.

Disclosure - AI to include Claude and Copilot were used to resolve the logic side of development of this project to break down the problems and to suggest classes/methods for research to use in development and to review completed code. All code was entirely written by myself.
